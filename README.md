# Інформаційна система реєстрації та опрацювання екологічних інцидентів

## Опис проєкту

Клієнт-серверна інформаційна система для реєстрації, моніторингу та опрацювання екологічних інцидентів.

Система дозволяє:
- реєструвати локації та екологічні інциденти;
- зберігати результати спостережень;
- створювати заходи реагування;
- розраховувати інтегральний показник інциденту;
- контролювати життєвий цикл інцидентів;
- імпортувати спостереження з CSV-файлу.

## Технології

- Java 21
- JavaFX
- Apache Tomcat 9
- MySQL
- Maven
- JDBC
- Jackson
- JUnit 5

## Структура проєкту

- `client` — JavaFX-клієнт.
- `server` — серверний Web-модуль, що містить Servlet, Service та DAO.
- `database.sql` — SQL-скрипт створення бази даних.
- `README.md` — опис проєкту та інструкція із запуску.

Клієнт взаємодіє із сервером через HTTP-запити. Сервер опрацьовує запити та працює з базою даних MySQL.

## Запуск проєкту

1. Створити базу даних за допомогою `database.sql`.
2. Налаштувати параметри підключення до MySQL у конфігурації сервера.
3. У каталозі `server` виконати команду `mvn clean package`.
4. Розгорнути отриманий WAR-файл у Apache Tomcat 9.
5. У каталозі `client` виконати команду `mvn javafx:run`.
